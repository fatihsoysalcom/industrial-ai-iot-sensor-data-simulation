# Industrial AI IoT Sensor Data Simulation

This Python script simulates IoT sensor data (temperature, vibration, pressure) from an industrial setting. It then uses simple AI logic to analyze this data, detect anomalies, and trigger alerts, demonstrating the core concept of AI-driven industrial decision-making beyond raw sensor readings.

## Language

`python`

## How to Run

1. Save the code as `industrial_ai_iot.py`.
2. Run from your terminal: `python industrial_ai_iot.py`.
3. Press Ctrl+C to stop.
